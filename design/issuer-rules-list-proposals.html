01

Rule Sentence

A rule is a sentence, so render it as one: “Match ALLIANZ I A R D on Compte courant, money out, €41.32.” The predicates become inline chips that only appear when they're set, so a plain regex rule stays a single quiet line and a four-predicate rule is visibly narrower in scope.

Gives up: column alignment. Chips are variable-width, so you can't scan “which rules are scoped to Compte courant” down a straight edge — fine at 1–8 rules, poor at 30.

02

Coverage Console

The question this tab actually answers is “are this issuer's transactions covered, and by what?” So lead with a coverage bar — 15 of 18 rows claimed by rules, 3 hand-assigned — and render the rules as a real table whose columns are exactly the predicate bar's four fields.

Gives up: comfort at N=1. A four-column table with a header row and a summary bar is heavy scaffolding for the single-rule issuer, which is most of them.

3 transactions on this issuer were assigned by hand and no rule can take them.
  • Columns mirror the predicate bar — account · pattern · direction · value, same order as the rule form, so editing feels like zooming into one row.
  • “Any” is printed, not omitted. An unset matcher reads as an explicit scope word, which is what makes two similar rules diffable at a glance.
  • Coverage bar on top answers the tab's real question before any rule is read, and surfaces the hand-assigned rows that rules will never claim.
  • Owns column is a right-aligned tabular figure, so the outlier zeros pop down the column; a 0 gets an amber badge.
  • Row actions fade in on hover — four rules × three always-on icons was twelve competing targets.
03

Rule Workbench

Stop sending people to another page to see what a rule does. A narrow rule rail on the left, and the selected rule's full predicate bar plus the transactions it owns on the right — the redesigned rule page, folded into the tab. Editing happens here; only “Add rule” navigates.

Gives up: simplicity and route parity. It duplicates a lot of the rule page inside a tab panel, and master-detail inside a tab inside a page is three levels of nested selection state.
